## Failures found

1. Incremental line offsets changed while the stored text did not, causing a live native panic. Iced/cosmic-text columns are UTF-8 bytes, not character counts.
2. Reopening a dirty tab replaced its rope with disk contents. Palette dispatch bypassed session-level rope parking.
3. Tab switches did not reliably queue a new preview; resetting the scheduler reused job IDs at identical document revisions.
4. Quit only checked the active tab. Closing an inactive tab could save the active one. Palette save/close effects were dropped.
5. View-mode state never changed the native split geometry; the hidden editor could still receive edits. Ordinary Command shortcuts were swallowed by the stray-character guard.
6. Word/character counts remained stale after native editing; verified in a real compositor capture.
7. Multi-tab restore was absent; restore also reset the document manager and dropped autosave bindings. Startup restoration could steal focus from an explicitly opened CLI file.
8. Unknown flags and extra CLI paths were ignored, including a production build's unsupported smoke flag.
